오늘 성서유니온 매일성경 본문(책·장절·찬송)을 가져와, 최근 일지·사역과 접목한 개인화 QT(핵심절·묵상·적용·기도)를 작성해 Supabase(daily_qt)에 저장한다. 분석 주체는 Claude Code(구독) — 종량제 API 미사용, 비용 0.

## 절차

1. **작업지시서 받기** — 실행한다:
   `npx tsx scripts/qt-pull.ts`
   (특정 날짜는 `npx tsx scripts/qt-pull.ts --date 2026-06-13`)
   stderr 한 줄 요약은 무시하고, **stdout 전체가 작업지시서**다(오늘 본문 · 개역개정 본문 · 작성 지시 · 가드레일 · result.json 형식 · 최근 일지·사역).

2. **QT 작성** — 작업지시서 [작성 지시]와 [신학 가드레일]·[기도제목 3원칙]·[톤]을 **그대로 충실히 따른다**:
   - key_verse: 본문 중 핵심 한 절을 개역개정으로 정확히 인용(책 장:절 표기, [개역개정 본문]에서 그대로).
   - meditation: 2~3문장, ★반드시 하나님의 구속(救贖) 사역과 연결.
   - application: [최근 일지·사역]에서 **실제** 연결고리를 찾아 1~2개(point + basis). 억지 연결 금지.
   - prayer_points: 1~2개(가정 평강·사역 기도 압축·온두라스 정치 중립).
   - ⚠ 성서유니온의 QT 제목·해설은 받지도 않았고 베끼지도 않는다. 본문(성경 말씀)에서 자체 작성.

3. **결과 저장 파일 쓰기** — 작업지시서의 `[result.json 형식]` 그대로 `insights-archive/_qt/result.json` 에 Write 한다(폴더 없으면 만든다. gitignore).

4. **DB 저장** — 실행한다:
   `npx tsx scripts/qt-push.ts`

5. **보고** — push 출력(날짜·본문·핵심절·적용·기도 수)을 한국어로 1~2줄 요약한다.

## 주의

- 저장 귀속 user_id 는 `.env.local` 의 `MFH_USER_ID`. 누락 시 push 가 안내 후 멈춘다.
- 같은 날(qt_date) 재실행은 **덮어쓰기**(하루 1행). 표시는 앱 `/qt` 전용 페이지(멤버 읽기) + 홈 카드.
- 저작권: 성경 본문 전체·성서유니온 묵상은 저장하지 않는다. 저장 대상 = 본문 메타(책·장절·찬송) + 핵심절 1개(개역개정 짧은 인용) + 자체 묵상·적용·기도.
- Cowork(아이폰 원격)에서 `/qt-update` 수동 호출, 또는 매일 05:00 자동 루틴이 같은 스킬을 실행(06:00 알림 발송).
