# MFH (Mission for Honduras)

선교 활동 기록·인사이트·포트폴리오 플랫폼.

## Stack
Next.js 14 (App Router) · TypeScript · Tailwind · Supabase · Vercel · PWA · Anthropic API.

## Env
`.env.local` (local) / Vercel Environment Variables:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `ANTHROPIC_API_KEY` (v2~)

## Build stages
v0 기반(스키마·Auth·오프닝·홈·일지) → v1 프로젝트·할 일 → v2 인사이트 → v3 편지·캘린더.
