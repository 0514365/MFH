# MFH 온두라스 동향 음성 브리핑 — 듣기 버튼 · 시리 단축어 설정

> "시리야, 온두라스 동향" 이라고 하면 단축어가 앱에서 오늘 브리핑 대본을 받아 시리 음성으로 읽어 준다.
> 앱 동향 화면의 **듣기** 버튼은 설정 없이 바로 쓴다. 2026-11-23 a단계(기기 음성) 기준.

## 구성

| 부분 | 위치 | 역할 |
|---|---|---|
| 낭독 대본 | `honduras_news.speech_script` (patch122) | `/news-update` 가 화면용 브리핑과 함께 쓰는 듣기용 글(3~4분) |
| 대본 조립 | `lib/honduras-speech.ts` | 대본이 없는 지난 동향은 제목·본문으로 즉석 조립 |
| 듣기 버튼 | `app/(app)/honduras/ListenButton.tsx` | 동향 화면 날짜 아래. 기기 내장 음성으로 재생·정지 |
| 단축어 API | `GET /api/honduras/speech` | 최신 동향 대본을 `text/plain` 으로 반환. `HONDURAS_SPEECH_TOKEN` 보호 |

- 대본에서만 지명·인명을 한글 발음으로 적는다(음성이 스페인어 철자를 읽지 못한다). 화면 표기는 원문 철자 그대로.
- 대본은 내부용이라 정당·인물 실명이 그대로 들어간다. 다른 사람이 듣는 자리에서는 유의.

## 1. SQL 적용 (1회)

Supabase 콘솔 SQL Editor 에서 `supabase/patch122-honduras-speech.sql` 실행.
적용 전에도 앱·루틴은 동작한다(듣기 버튼과 단축어는 조립본을 읽고, 루틴은 대본만 빼고 저장).

## 2. 토큰 만들기 · Vercel 등록 (1회, 단축어용)

1. Mac 터미널에서 임의 토큰 생성:
   ```bash
   openssl rand -hex 24
   ```
2. Vercel → 프로젝트 → Settings → Environment Variables → `HONDURAS_SPEECH_TOKEN` = (위 값), Environment **Production** → Save.
3. Deployments → 최신 배포 **Redeploy**(환경변수는 재배포해야 반영).
4. 토큰은 단축어에만 넣는다(채팅·문서·git 에 남기지 않기). 카드 문자용 `SMS_INGEST_TOKEN` 과는 다른 값을 쓴다(이쪽은 읽기 전용).

## 3. 연결 테스트

`<TOKEN>` 과 `<APP>`(배포 URL)을 바꿔서 실행:

```bash
curl -s "https://<APP>/api/honduras/speech" -H "Authorization: Bearer <TOKEN>"
```

- 기대: "○월 ○일 온두라스 동향입니다. …" 로 시작하는 글.
- `unauthorized` 면 토큰 값 또는 재배포 확인.

## 4. iPhone 단축어 만들기

단축어 앱 → **+** → 이름을 **온두라스 동향** 으로(이 이름이 시리 호출어가 된다).

1. 동작 추가 → **URL 내용 가져오기**
   - URL: `https://<APP>/api/honduras/speech`
   - 펼치기(>) → 방법 **GET** → 헤더 추가: 키 `Authorization`, 값 `Bearer <TOKEN>`
2. 동작 추가 → **텍스트 말하기**
   - 입력: *URL 내용*
   - 펼치기(>) → 언어 **한국어**, 음성은 원하는 시리 음성, 속도 조절 가능
   - "완료될 때까지 기다리기" 켬

사용: "시리야, 온두라스 동향". 홈 화면에 추가하거나 운전 중 CarPlay 에서도 같은 말로 실행된다.

> 음성 선택지에 고음질 음성이 없으면 설정 → 손쉬운 사용 → 읽기 및 말하기(구 "말하기 콘텐츠") → 음성 → 한국어에서 내려받는다.

## 5. 아침 자동 재생 (선택)

단축어 앱 → **자동화** → **+** → **특정 시간**(예: 07:00, 매일) → "즉시 실행" → 위 **온두라스 동향** 단축어 실행.
동향 루틴은 매일 06:00 에 돌기 때문에 그 이후 시간으로 잡는다.

## 한계 · 다음 단계
