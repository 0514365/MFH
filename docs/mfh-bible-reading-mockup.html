계정당 활성 계획 1개(DB partial unique). 완독(모든 날 체크) 시 자동으로 「완독」 상태. 삭제는 확인 후 일정·기록 함께 삭제(연결된 일지는 남김).

범위 표기 규칙: 같은 권 → 「창세기 1~15장」, 권이 바뀌면 → 「베드로후서 3장 ~ 요한계시록 6장」(README 8절). 홈·목록에서는 공간이 좁으면 약어(「벧후 3 ~ 계 6」, lib/bibleAbbr.ts 재사용).
상태 배지: 일정대로(밀린 날 0) · N일 밀림(오늘 이전 미체크 일수) · 완독.
기도제목 포함: 토글 ON 시 일지(Log)에 분류 「성경통독」, 머릿말 = 범위, 기도 = 은혜 한 줄, 기도후보 ON 으로 자동 생성 → 기존 선교편지 기도제목 수집 흐름에 그대로 합류. OFF 로 되돌리면 그 자동 일지는 삭제.
