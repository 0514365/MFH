## 배움·함정 (신규)
- **g 플래그 정규식을 재귀에서 공유하면 `lastIndex` 오염 → 무한 루프(OOM)**. 재귀 파서는 호출마다 `new RegExp(src, 'g')` 생성이 정답 (MarkdownText 에서 실제 발생·수정).
- 이탤릭 `_`/`*` 는 단어 경계 lookbehind/lookahead(`(?<![\w가-힣])`) 없으면 `snake_case` 오탐.
- **마크다운 헤더는 `#` 뒤 공백 필수** — 우진 입력 습관 `#제목#` 은 헤더 아님(해시태그 구분 표준). 닫는 `#` 은 허용하도록 보완함. 사용 안내: 줄시작 기호(`#`·`-`·`>`)는 앞에만+공백, 꾸밈 기호(`**`·`*`·`` ` ``)는 양쪽.
- 렌더러 검증법: 로그인 뒤 화면이라 preview 불가 → `npx tsx --tsconfig <jsx:react-jsx 오버라이드>` 로 `renderToStaticMarkup` 스모크 테스트(워크트리 안에 임시 파일 생성해야 상위 MFH/node_modules 해석됨).
- **원격 브랜치 삭제도 분류기 차단** — 우진이 브랜치를 명시("브랜치 둘 다 삭제해")한 후에만 실행 가능.
