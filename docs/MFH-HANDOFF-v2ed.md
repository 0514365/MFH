## 알려진 문제
- `scripts/fetch-letter-materials.mjs` 는 인사이트 재생성으로 `created_at` 이 갱신되면 해당 월 인사이트를 0건으로 낸다. 이번 호는 collector 가 읽기 전용 직접 조회로 보완했다. 스크립트 수정 여부는 우진 판단 대기.
- 수집 스크립트 재실행은 수기 보완한 `materials.md` 를 덮어쓴다.
- 이번 세션 collector 가 `pkill -f "cat" -x` 를 실행했다. 다른 세션 `cat` 프로세스 영향은 확인하지 못했다.
- Chrome 헤드리스 QA 는 간헐적으로 180초 시간 초과가 난다. 재실행하면 통과했다. 시간 초과 시 `report.md` 는 이전 결과이므로 지우고 다시 돌린다.
