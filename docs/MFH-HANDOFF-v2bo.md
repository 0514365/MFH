## 이번 세션 작업 — 비서 카드 UX + 문체

## 핵심 메모 (다음 세션)
- **DB 스키마 변경 없음** — `insights` 테이블 그대로. 비서는 `domain=project_assist·task_assist` 행. push 는 content·기간만 갱신하고 별점·메모·in_letter 보존.
- **렌더링 규칙**(`InsightContent`): 줄 전체 볼드=소제목 / 비서 도메인의 `**라벨** · 본문`=강조 박스 / 그 외 인라인 볼드는 그대로. 인사이트 소제목도 같은 타이틀 스타일을 공유한다.

- 검증: `tsc`·`build` 통과 / push 2/2 / 우진 수정본 DB 반영. 배포는 Vercel auto-build.
