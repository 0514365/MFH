# MFH 온두라스 동향 — 출처·전략 정리

> 작성: 2026-06-24 (핸드오프 v2cd 세션). 개정: 2026-06-25 — 4분야(정치·경제·사회·문화) **48h 당일 필수**·빈칸 "특이사항 없음"·안전② 한인 대체. `news-update` 최신성 개선 작업에서 도출한 연구·결정 사항을 참조용으로 정리한다.
> 관련 코드: `scripts/news-pull.ts`(작업지시서) · `scripts/news-push.ts`(저장) · `.claude/commands/news-update.md`(스킬) · `app/honduras/BriefingView.tsx`(표시).

---

## 1. 기능의 목적 (왜 존재하는가)

매일 아침 **"그날의 최신" 온두라스 동향**을 확인하기 위한 내부 페이지. 지난 소식은 `/honduras/archive` 에 자동 보관된다.
→ **핵심 원칙: 오래된 기사로 칸을 채우지 않는다(최신성 우선).** 단 정치·경제·사회·문화 4분야는 "당일 필수"라 통째로 비우지 않고, 정말 없을 때만 "특이사항 없음"으로 표시한다. San Pedro Sula·한인 하이라이트는 새 소식 없으면 비우는 것이 정답.

(과거 문제: "최신만 보고 싶은데 지난 기사가 최신처럼 올라옴" → 아래 최신성 차등·발행일로 해결.)

## 2. 분야별 최신성 차등 (이 개선의 핵심)

| 분야 | 임계 | 빈칸 정책 |
|---|---|---|
| 정치·경제·사회·문화 | **발행일 48h 이내만** | **당일 필수** — 통째 생략 금지. 광범위 검색 후에도 없을 때만 빈 배열 → 앱이 "특이사항 없음" 표시 |
| San Pedro Sula | 7일 내 새 소식만 | 없으면 비움 |
| 한인 | 14일 내 새 소식만 | **없는 게 정상**(아래 6번) |
| 안전(safety) | 신규·갱신 경보만 + 한인 공백 시 치안 핵심 승격 | 공식경보·한인 모두 없으면 그날 치안 1건을 tag "안전"으로 대체(아래 7번 ②) |

빈 하이라이트(셋 다 없음) → 최신 페이지에만 *"최근 새 소식 없습니다 · 지난 동향 보기"* 안내.
4분야(정치·경제·사회·문화)는 빈 분야도 **"특이사항 없음"** 칸으로 항상 노출(누락 vs 무소식 구분).

> **개정 이력**: 06-24 최초(정치·경제·사회 72h / 문화 7일·생략). 06-25 변경 → **4분야 48h 당일 필수 + 빈칸 "특이사항 없음"**(문화 승격, 72h→48h). 이유: 4분야는 매일 새 소식이 있어 "무소식"이 곧 검색 누락 신호 → 누락과 진짜 무소식을 화면에서 구분.

## 4. 온두라스 언론 환경 (편향·신뢰도 — 교차확인이 필요한 이유)

- **소유 집중**: OPSA = `El Heraldo` + `La Prensa` 소유 / Periódicos y Revistas = `La Tribuna`(전 대통령 Carlos Roberto Flores 소유)·`El País` 등.
- **편향**: 3대지는 소유주·정파에 불리한 사안을 다루지 않는 경향. `El Heraldo` 는 보수·군부 친화로 평가.
- **신뢰**: 소비량은 많으나 신뢰도는 낮음 → 젊은·도시 독자는 SNS·온라인으로 이동.
- **독립·탐사**: `Contracorriente`(2017 창간, 부패·정치·인권), `Criterio.hn`(JOH 마약·부패 탐사). 단 일부에서 자금 네트워크(CAPIR/Connectas) 비판 시각도 존재 — 인지하되 국제 언론자유 단체는 이들에 대한 탄압을 우려.
- **결론**: 단독 보도보다 **여러 매체가 공통 보도한 사안을 우선**한다.

## 5. San Pedro Sula 현황

- **La Prensa 본사가 산페드로술라**(1964 창간) → `laprensa.hn/sanpedro` 전용 섹션.
- `elpais.hn`(노티시아스 산페드로술라 섹션), `hch.tv`, `tiempo.hn` 도 커버.
- 일반 "뉴스"는 한인보다 잦으나, **그날 별도 강조할 거리는 매일 보장되지 않음** → 새 소식 있을 때만.

## 6. 한인 현황 (왜 매일 소식이 없는가)

- **재온두라스 한인 약 280명**(2023 기준 — 테구시갈파 75명, 산페드로술라 등 210명).
- **한인회는 2021년부터 구성되지 못한 사실상 휴면 상태.**
- 1차 출처: 주온두라스 대한민국 대사관(`overseas.mofa.go.kr/hn-ko`), 재온두라스 한인회 Facebook(거의 비활성).
- → **한인 뉴스가 매일 없는 것이 정상.** 억지로 채우지 말고 비운다. 14일 창으로 넓게 잡아 새 소식이 있을 때만 강조.

## 8. 검색 전략

- **스페인어가 1차**(현지 매체), 영문으로 교차·안전 보강. 쿼리에 `hoy` / 날짜(`junio 2026`)를 넣어 최신을 노린다.
- WebSearch 호출 시 위 티어 도메인을 `allowed_domains` 로 지정 → 최신·신뢰 결과로 좁힘.
- **각 기사의 발행일을 반드시 확인**(스니펫·본문·URL). 끝내 불확실하면 제외하거나 발행일 빈값.
- 표준 깊이 = 약 8~9회(정치·경제·사회·문화 각 1, 영문 교차 1, San Pedro Sula 1, 한인 1, 안전 1). 4분야는 당일 필수라 빠짐없이 검색.

### ⚠ 운영 함정
- `reuters.com` · `apnews.com` 은 **Anthropic 크롤러 차단(400 에러)** → 영문 교차는 elfaro/insightcrime/ticotimes/aljazeera 위주로.
- 한인 검색은 도메인 제한 없이(대사관·한인 카페·블로그 등 다양, 소식 희소).

## 9. 데이터·표시

- **`published_at`("YYYY-MM-DD")**: 각 항목에 기사 발행일. `sections`/`highlights` **jsonb 안에** 저장 → DB 스키마 무변경. 형식 아니면 `news-push` 가 `null` 로 정규화.
- **발행일 배지**(`BriefingView.relDay`): 브리핑 날짜 대비 `오늘 / 어제 / N일 전(13일까지) / M·D`. 발행일 불명(null)이면 배지 없음.
- **빈 분야 표시**(`BriefingView` 4분야): 정치·경제·사회·문화는 빈 배열이어도 섹션을 숨기지 않고 점선 박스 **"특이사항 없음"** 으로 노출(당일 필수 분야의 누락 vs 무소식 구분).
- **안전 tag**: `highlights` 박스 제목 = "주목 · San Pedro Sula · 한인 · 안전". tag 값 = `"San Pedro Sula"` | `"한인"` | `"안전"`.
- **실명 기재 OK**(내부 동향 파악용): 정당명·인물명 사실대로. ⚠ 단 월간 편지·Facebook·포트폴리오 등 **외부 발신물에 옮길 때는 정치중립 규칙(정당·인물 거명 회피)을 다시 적용**한다.
