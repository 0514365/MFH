### 1. 모바일 → 카드뉴스 PDF 변환 리허설 (6월호 "세움의 계절")
- 모바일 확정본 원고·기도제목을 **그대로** 카드뉴스 14장으로 변환. 색·톤도 모바일 마룬(`#6A2323`)에 통일(마스터 `mfh-cardnews.html`의 에디토리얼 레이아웃 자산은 차용하되 색은 모바일 기준).
- 구성: ①표지 ②여는글 ③온두라스 ④⑤ICAS ⑥⑦성경공부 ⑧⑨단기팀 ⑩⑪건축 ⑫LasBrisas ⑬가정 ⑭마무리. 2면이던 사역은 1면(대표 풀블리드)/2면(보조 듀얼·트리오)으로 분할.
- 우진 다회 수정 반영(→ 그 공통점을 designer 팁으로 정착): 본문·기도·표지하단 **폰트 확대**, 짧은 면 **사진 확대로 여백 제거**, 성경공부2 **왼쪽 세로1+오른쪽 가로2 트리오**, 가정 **타이틀 상단행→본문좌·세로사진우(높이동일)→기도 하단행**(가족 6명 전원 노출), 표지 **머리 위 크롭·허리선까지 축소·타이틀 상체 걸침**, 마무리 **MFH로고·카톡QR·이메일 3아이콘 한 행**(앱·이메일은 클릭 링크).
- 출력: Chrome headless `--headless=new --no-pdf-header-footer --print-to-pdf` + `@page{size:1080px 1350px;margin:0}`. 게시용 경량화 = 사진 긴변 ~1600px·품질80 리사이즈 사본 `photos-web/`(원본 `photos/`는 모바일용 보존) → **96MB → 18.6MB**.
