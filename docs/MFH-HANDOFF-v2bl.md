## 이번 세션 작업 (커밋 순)

### 1. 프로젝트 할 일 수동 순서 — patch95 (`3c22039`, `fa9ca7e`)
- `tasks.sort_order int` + 프로젝트별 기존순서 백필 + `(project_id, sort_order)` 인덱스 + **`swap_task_sort_order` RPC**(SECURITY DEFINER — 프로젝트 소유자·마스터 검증, 같은 프로젝트, sort_order 만 원자 교환). RLS(본인 task 만 update) 우회를 sort_order 에 한해 안전하게 허용.
- `TaskForm`: 프로젝트 연결 시 맨 끝(`max+10`)으로 자동 배치(신규·반복·편집 중 프로젝트 변경). 단독 할 일은 null.
- 정렬: `미완료(sort_order↑) → 완료(sort_order↑)`. `projects/[id]/page.tsx` select·order 변경.
- **`ProjectTaskList.tsx`(신규 클라 컴포넌트)**: 목록 렌더 + 재정렬을 page(서버)에서 분리.

### 2. 선행/후속 관계 — patch96 (`738c393`)
- `tasks.predecessor_ids`·`successor_ids uuid[]`(관계 표시용, **순서와 독립**, SQL 은 컬럼 2개만 — jsonb 아님).
- 같은 프로젝트 할 일만 후보로 선택.

### 3. 상세 UI 개선 (`b691af8`, `bbe5bbe`)
- **그룹 영역 분리**: `To-do(남은 N)` / 구분선 / `Done(완료 N)`, 완료는 취소선.
- **상시 ▲▼ 재정렬**: "순서 편집" 토글 제거 → 날짜 우측에 **가로 배치 큰 버튼**(↑↓) 상시 노출(소유자·마스터, 같은 그룹 내 인접 swap → RPC → refresh).
- **선행/후속**: 체크리스트(다중) → **드롭다운 단일 선택**(선행 1·후속 1, "관련 프로젝트"와 동일 패턴). 프로젝트 바꾸면 후보 갱신·무효 선택 자동 해제. 상세 행 아래 "선행/후속 ○○" 표시(id→제목 변환).

### 4. 온두라스 동향 출처 기사 링크 (`301bed0`)
- `sections`/`highlights` item 에 `url` 추가(**jsonb 구조라 SQL 무변경**). `BriefingView`: `url`(또는 `source` 가 http)이면 새 탭 링크(`출처 · 매체명 ↗`), URL 만이면 도메인 축약.
- `scripts/news-push.ts`: `url` 정규화·저장. `scripts/news-pull.ts`: 작업지시서 형식·정리규칙에 `url`(기사 원문 링크) 수집 지침.
