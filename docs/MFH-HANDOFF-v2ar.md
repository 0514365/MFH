## 설계 결정

- **단일 복제(상세·요약 버튼)는 그대로** `(사본)` 후 폼에서 수정 — 목록 복제만 자동번호(우진 요청 범위).
- **목록 복제 = 직접 DB 복사**(폼 미경유): 다건을 폼으로 받을 수 없으므로. 단건 신중 복제는 상세/요약의 복제(폼 프리필)로 계속 가능.
- **자동번호 기준 = 현재 로드된 목록 제목**: 제목은 DB 유니크 키가 아니므로 "보이는 중복 회피"가 목적. best-effort.
