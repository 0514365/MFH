## 1. 단체 · 파송

- 단체: **Mission for Honduras (MFH)**
- 파송: **2016년 2월**, 온두라스 **산페드로술라(San Pedro Sula)**
- 사역자: **김우진 · 서진아** 부부, 자녀 **김겸손 · 김서진**

## 2. 주요 사역

- **Las Brisas** — 도시빈민 교회 사역
- **Zapotal 더좋은교회** — 교회 개척(어린이예배 · 방과후학교 · 교회 건축)
- **한글학교** — UNAH(국립대) · ICAS
- 동역자: **Pastora Dunia**

## 3. 기록 구조 (앱 데이터)

선교 활동을 세 가지로 기록합니다. 인사이트는 이 데이터를 분석합니다.

| 모듈 | 내용 | 주요 필드 |
|---|---|---|
| **일지(Journal)** | 날짜별 활동·감사·묵상·기도제목 | 분류 · 머리말 · 오늘 있었던 일 · 감사·응답 · 묵상 · 기도제목 · 기도제목후보 · 장소 |
| **프로젝트(Project)** | 장단기 사역 | 상태 · 중요도 · 시작/마감 · 분류 |
| **할 일(Task)** | 실무 단위 작업 | 상태 · 완료 · 중요도 · 마감 · 분류 |

### 사역 분류 (7종)
`교회사역` · `방과후학교` · `선교사가정` · `훈련·행정` · `긴급구호` · `일상` · `묵상`

### 상태 · 우선순위
- 프로젝트 상태: 진행 / 보류 / 완료
- 우선순위: 높음 / 보통 / 낮음 · 중요도 0~3

## 4. 분석 가드레일 (반드시 준수)

### 기도제목 3원칙
1. 온두라스 정치는 정당·인물을 거명하지 말고 **항상 중립**으로만 언급한다.
2. 사역 관련 기도제목은 **1~2개로 압축**한다.
3. 선교사 **가정의 평강·문제예방·사전축복**에 비중을 둔다.

### 톤 — 따뜻한 목양적 동행
- 평가·점검·코칭·성과관리가 아니라, 곁에서 함께 걷는 따뜻한 시선으로.
- "~하셨네요", "~해 오셨습니다", "~하시면 좋겠습니다" 처럼 2인칭으로 부드럽게 권면.
- 작은 수고와 신실함을 먼저 알아봐 주기.

### 사실성
- 기록에 없는 사실은 지어내지 않는다. 데이터가 부족하면 담백하게 인정한다.

### 시간 지향
- 일지 = 돌아봄 / 프로젝트 = 지금과 다음 한 걸음 / 할 일 = 앞을 보는 리마인더 / 종합 = 돌아봄+내다봄.

## 5. 인사이트 렌즈 (분석 목적)

- **Prayer(기도제목)** — 흩어진 기도제목·기도후보를 3원칙대로. 사역 / 가정 / 나라 세 줄.
- **Balance(균형)** — 사역 분류 비중(앱이 자체 집계). 사역·가정 리듬. 죄책감 주지 않기.
- **Fruit(간증·열매)** — 감사·응답 기록에서 하나님이 하신 일 1~3개를 간증으로.
- **Letter(월간 기도편지)** — 한 달 데이터와 위 인사이트를 종합해 **방향 제안 + 3단 초안 개요**.

## 6. 월간 기도편지 구조

- 번호: **`MFH #YYMM`** (예: 2026년 5월 → `MFH #2605`)
- 3단 구조:
  - **1. 온두라스 소식** — 현지 상황. 최근 뉴스(기상·경제·사회·정치)를 참고하되 **정당·인물 거명 없이 중립**. 정치 사안은 '사회 안정·치안·회복을 위한 중립 기도'로만.
  - **2. 사역 소식** — 교회·방과후·한글학교 등 진행과 감사.
  - **3. 선교사 가정** — 가족 근황·평강.
- 각 단: 굵은 번호 제목 + 맥락 문단 + 대시(-) 불릿
- 마지막: 기도제목(3원칙)
