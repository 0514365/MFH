# MFH 선교편지 제작 워크플로

> 매달 사진·기록을 모아 → 마스터 템플릿으로 편지를 (반)자동 생성하는 절차.
> 방식: **하이브리드** — MFH 앱(수집) + Claude(생성) + Canva(손맛 보조).

---

## 1. 마스터 템플릿 (`letter-templates/`)

| 파일 | 용도 | 규격 |
|------|------|------|
| `mfh-cardnews.html` | 카드뉴스 (표지·내지·마무리) | 4:5 (1080×1350) |
| `mfh-mobile-letter.html` | 모바일 세로 스크롤 페이지 | 폭 430, 가변 |
| `mfh-redesign.html` | 표지 단독 (SNS 대표 1장) | 4:5 |
| `assets/cover.jpg` | 이달의 대표 사진 (매달 교체) | 가로 권장 |
| `assets/온두라스로고4.png` | 로고 (고정) | — |

디자인 언어: 파스텔 톤 + 온두라스 지도 로고 + 명조 제목(Nanum Myeongjo). 브랜드 마룬은 사용하지 않음.

---

## 2. 매월 색 바꾸기 — 파스텔 베리에이션

각 HTML 파일 상단 `:root` 의 **`--cool` / `--accent` 두 줄만** 교체하면 전체 톤이 그달 파스텔로 바뀐다 (나머지 색은 `color-mix`로 자동 파생).

| 월 | 조합 | `--cool` | `--accent` |
|----|------|----------|------------|
| 6월 | 블루 + 피치 | `#B9D2E8` | `#EFC6B0` |
| 7월 | 민트 + 버터 | `#BFE0D2` | `#F3D9A8` |
| 8월 | 라벤더 + 핑크 | `#D6C8E8` | `#F0C0CE` |
| 9월 | 세이지 + 살구 | `#CFE0B8` | `#EBC9A0` |
| 12월 | 세이지 + 소프트레드 | `#B8D8C8` | `#E9B7B0` |

(원하는 파스텔로 자유롭게. 쿨 1색 + 웜 1색 조합이면 균형이 잡힌다.)

---

## 3. 매달 절차

1. **수집 (상시)** — MFH 앱 *일지*에 사진 + 한 줄 기록. 사진에 섹션 태그(온두라스 / 사역 / 가정).
2. **패키징 (월말)** — 그달 일지·사진을 모은다. 대표 사진 1장 + 섹션별 사진 몇 장.
3. **생성 (Claude)** — 재료를 Claude에 주고 *"이 마스터 템플릿으로 이번 달 편지"* 요청. 사진 수·종류에 따라 레이아웃을 약간 변형해 받는다.
4. **채우기** — `assets/cover.jpg` 교체, 텍스트의 `[   ]` 부분 채움, 색 변수 교체.
5. **출력** — 브라우저로 열고 `Cmd+P → PDF로 저장` (카드뉴스/표지는 카드 우클릭 → 이미지로 저장).
6. **등록** — MFH 앱 포트폴리오 *선교편지 관리*에 업로드 (PDF / 표지 / 요약 기도문).

## 4. Claude에 줄 "재료" 형식 (예)

```
발행: 2026년 6월 · MFH #2606
연 주제: 강가에 심긴 나무처럼
타이틀: 비를 기다리는 땅에서 / 부제: 메마른 땅에 다시 흐르는 은혜
말씀: 이사야 43:19
이달 색: 7월 민트+버터 (--cool #BFE0D2 / --accent #F3D9A8)

[온두라스]  우기 시작, 물가 …
[사역]      청소년 모임 … (사진 3장)
[가정]      자녀 학기 적응 …
[기도제목]  사역 1~2 / 가정 1 / 나라 1 (중립)
대표사진:   cover.jpg
```

→ Claude가 위 마스터 HTML에 데이터를 채우고, 사진 수에 맞춰 내지 레이아웃을 변형한 그달 버전을 생성.

도메인 규칙(필수): 온두라스 정치 중립(정당·인물 거명 금지) · 사역 기도제목 1~2개 압축 · 가정 평강·축복 비중.

---

## 5. 차후 자동화 (앱 보강 — 선택)

- 앱에 **'그달 재료 내보내기'**: 일지+사진 → 편지 재료(JSON/zip) 한 번에.
- 기존 **letter 인사이트**(일지+프로젝트+할일 종합 AI 초안)와 연결 → 글 초안 자동.
- 템플릿에 데이터 바인딩 → 버튼 한 번으로 반자동 생성 (Claude Code 개발 영역).
