# MFH 선교편지 제작 지침

> 매달 사역 기록·사진을 모아 → 마스터 템플릿으로 편지를 만드는 **표준 프로세스·사양**.
> 방식: 하이브리드 — MFH 앱(수집) + Claude(작성·디자인) + 출력(PDF).
> 첫 버전 확립: 2026-06 (5월 편지 시연으로 프로세스·템플릿 확정).

---

## 1. 작성 프로세스 (★ 매 단계 검토·확정 후 진행)

> Claude 가 자료를 수집하더라도 **곧바로 완성하지 않는다.** 단계마다 우진의 검토·승인을 받은 뒤 다음으로 간다.

```
① 자료 수집     앱 일지/DB에서 그달 사역기록·사진 수집 (Claude)
       ↓
② 분석 → 방향   내용 분석 후 편지 방향 2~3개 제안 + 추천      → 검토·확정
       ↓
③ 제목·본문     제목 후보 + 본문·기도제목 초안 (텍스트만)     → 검토·확정
       ↓
④ 레이아웃 시안  사진·글 배치한 실제 편지 이미지/PDF           → 검토·확정
       ↓
⑤ 최종 출력     PDF 출력 + 앱 포트폴리오 등록
```

- ③에서 **글(내용)만** 먼저 확정한다. 디자인은 ④에서.
- ④는 반드시 **실물(이미지/PDF)** 로 보여주고 확정받는다.
- 도메인 규칙(아래 4)은 ③·④에 항상 적용.

**로고·아이콘 배치 (고정 규칙)**

| 자산 | 위치 |
|------|------|
| `logo-primary.png` (Brand kit 교회 로고) | 표지 헤더 · 마무리 푸터 |

**디자인 사양**
- 제목 폰트: 명조 **Nanum Myeongjo** / 본문: Pretendard / 라벨·숫자: Montserrat
- 표지 하단 **별 모티프 없음** (제거됨)
- 내지 상단 = **테마 컬러 헤더 띠**

- 연 주제 표기: **"2026년 주제 · 주님은 길을 내십니다"** (※ "연 주제" 아님)

## 3. 기본 테마색 (첫 버전 — 6월부터 적용)

브랜드킷(마룬·레드)의 **파스텔 톤**. `mfh-cardnews.html` 의 `:root` 두 색만 바꾸면 전체가 파생된다.

| 토큰 | 값 | 용도 |
|------|----|----|
| `--cool` | `#DCC2C3` 더스티 로즈(마룬 파스텔) | 면·헤더띠·테두리 |
| `--accent` | `#EFC8B8` 살구코랄(레드 파스텔) | 칩·부제·포인트 |
| `--navy` | `#5E2A2B` 딥마룬 | 제목·CTA·강조 |

> 월별 색 변주를 원하면 `--cool`/`--accent` 두 색만 교체 (예: 7월 민트+버터 `#BFE0D2`/`#F3D9A8`). **기본은 위 브랜드 파스텔 고정.**

---

## 4. 기도제목 규칙 (고정)

- **순서: [온두라스] → [사역] → [가정]** (항상 이 순서)
- 타이틀은 **"나라" 대신 "온두라스"**
- 3원칙: ① 온두라스 정치 중립(정당·인물 거명 금지) ② 사역 기도제목 1~2개 압축 ③ 가정 평강·문제예방·사전축복

---

## 5. 자료 수집 — 두 경로

- **완전자동(권장)**: 이 창(Claude Code)에서 — Claude가 그달 일지·사진을 DB/폴더에서 직접 가져와 ①~⑤ 진행.
- **앱 경로(보조)**: 앱 `/letter-materials`(insights에서 진입) → 텍스트 복사 + 사진 다운로드 → Claude에 첨부. (무료, RLS)

**Claude에 줄 재료 형식 (예)**
```
발행: 2026년 6월 · MFH #2606
이달 핵심: (사역 요약)
사진: (대표 1장 + 섹션별)
```
→ Claude가 ②분석부터 시작.

---

## 6. 출력·활용

- ⑤ 출력: 편지를 브라우저로 열고 `Cmd+P → PDF로 저장` (또는 자동 PDF). 카드 이미지는 우클릭 저장.
- 앱 포트폴리오 *선교편지 관리* 에 업로드(PDF·표지·요약).
- SNS·카톡 공유.
