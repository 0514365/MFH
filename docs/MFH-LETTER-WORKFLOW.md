# MFH 선교편지 제작 지침

> 매달 사역 기록·사진을 모아 → 마스터 템플릿으로 편지를 만드는 **표준 프로세스·사양**.
> 방식: 하이브리드 — MFH 앱(수집) + Claude(작성·디자인) + 출력(PDF).
> 첫 버전 확립: 2026-06 (5월 편지 시연으로 프로세스·템플릿 확정).

---

## 1. 작성 프로세스 (★ 매 단계 검토·확정 후 진행)

> Claude 가 자료를 수집하더라도 **곧바로 완성하지 않는다.** 단계마다 우진의 검토·승인을 받은 뒤 다음으로 간다.

```
① 자료 수집     앱 일지/DB에서 그달 사역기록·사진 수집 (Claude)
       ↓
② 주제→기조문→개요문  주제 후보 2~3 → 기조문(도입·강조점) → 개요문(사실 골자·사진·기도)  → 각 승인
       ↓
③ 본문 초안     개요로 사실 보고 본문(완성 초안) + 사진 배치 계획                       → 검토·수정·확정
       ↓
④ 모바일 디자인  모바일 letter.html (Variant 베이스 · 1면 1주제 · 사진 우선)            → 검토·확정
       ↓
⑤ 카드뉴스 변환  확정 모바일본 → 카드뉴스 PDF(4:5) 변환 (내용 동일 · 지면 특성상 레이아웃 일부 변경·사진 일부 추가)  → 검토·확정
       ↓
⑥ 출력·등록     모바일 HTML(메인) + 카드뉴스 PDF(오프라인 게시) + 앱 포트폴리오 등록
```

- ③에서 **글(내용)만** 먼저 확정한다. 디자인은 ④에서.
- ④는 반드시 **실물(이미지/PDF)** 로 보여주고 확정받는다.
- **사진 운용 규칙(④에서 항상 적용)**:
  - 사역 사진이 있는 섹션 → 사진을 **풀블리드로 온전히** 보여주고 제목·본문은 **사진 밖(아래)**. **사진 위에 텍스트를 얹어 가리지 않는다** (사역 사진은 디자인 요소가 아니라 '사역의 증거').
  - 사진이 없는 섹션 → 처리법을 **우진에게 물어** 정한다(주제마다 다름): ① 참고/무드 사진 넣기 ② 본문 중심 타이포.
  - 참고사진을 넣기로 하면 → **우진이 제공하는 현지 사진을 우선**한다(스톡보다 진정성·적합성↑). Claude는 **어떤 컨셉·분위기의 사진이 좋을지 먼저 제안**하고(예: "우기의 먹구름 하늘, 차분한 톤"), 우진이 그 컨셉에 맞는 사진을 준다. 우진이 못 줄 때만 스톡(CC0)에서 후보를 찾아 제시한다.
  - **사진이 여러 장**인 섹션 → 레이아웃을 주제·장수에 맞게 고른다: ① 각각 분리(단계·서사 강조 시, 예: 건축 3단) ② **콜라주/모자이크로 하나의 비주얼로 묶기**(큰1+작은N · 2×2 · 상1+하3 등 — 여러 장면을 한눈에) ③ 대표 1장 풀블리드. 정답은 없으니 주제·사진에 따라 ④에서 우진과 함께 정한다.
- 도메인 규칙(아래 4)은 ③·④에 항상 적용.

## 2. 마스터 템플릿 & 사양

| 파일 | 용도 | 규격 |
|------|------|------|
| `letter-templates/mfh-cardnews.html` | 카드뉴스 마스터(표지·내지·마무리) | 4:5 (1080×1350) |
| `letter-templates/mfh-mobile-letter.html` | 모바일 세로 스크롤 | 폭 430 |
| `letter-templates/assets/` | 로고·아이콘 (고정) | — |
| `letter-templates/issues/<YYYY-MM>/` | 그달 재료·사진·결과물 (git 제외) | — |

**로고·아이콘 배치 (고정 규칙)**

| 자산 | 위치 |
|------|------|
| `logo-primary.png` (Brand kit 교회 로고) | 표지 헤더 · 마무리 푸터 |
| `온두라스로고4.png` (지도 로고) | 마무리 상단 |
| `mfh-icon.png` (MFH 앱 아이콘) | 마무리 CTA 박스 |

**디자인 사양 (V4 에디토리얼 — 2026-06 리허설로 확정)**
- 제목 폰트: 명조 **Nanum Myeongjo** / 본문: Pretendard / 라벨·숫자: Montserrat
- **표지**: 사진 hero 풀(~70%) + 제목 오버레이
- **사역 사진 내지**: 풀블리드로 온전 + 제목은 사진 **밖**(텍스트로 가리지 않음)
- **내지 헤더**: 슬림(70px) **미드그레이 띠** `#45454F` + 레드 짧은 바
- 본문·기도제목 **글자 크게**(가독성 우선)
- 연 주제 표기: **"2026년 주제 · 주님은 길을 내십니다"** (※ "연 주제" 아님)

## 3. 기본 테마색 (V4 에디토리얼 — 2026-06 리허설로 확정)

차콜 + 브랜드 레드. **골드·파스텔 폐기.** `mfh-cardnews.html` 의 `:root` 기준.

| 토큰 | 값 | 용도 |
|------|----|----|
| `--red` | `#C5283D` 브랜드 레드 (+`--red-d #9E1F30`·`--red-l #E2697A`) | 칩·기도라벨·불릿·라인·하단바 |
| `--hdr` | `#45454F` 슬림 미드그레이 | 내지 헤더띠(70px) |
| `--navy` | `#5E2A2B` 딥마룬 | 명조 제목 |
| `--char` | `#17171C` 차콜 | 사진 scrim·CTA 박스 |

> 월별 변주는 `--red` 톤으로. 구 파스텔(`--cool`/`--accent`)·V3 마스터는 `letter-templates/archive/` 에 백업.

## 4. 기도제목 규칙 (고정)

- **순서: [온두라스] → [사역] → [가정]** (항상 이 순서)
- 타이틀은 **"나라" 대신 "온두라스"**
- 3원칙: ① 온두라스 정치 중립(정당·인물 거명 금지) ② 사역 기도제목 1~2개 압축 ③ 가정 평강·문제예방·사전축복

---

## 5. 자료 수집 — 두 경로

- **완전자동(권장)**: 이 창(Claude Code)에서 — Claude가 그달 일지·사진을 DB/폴더에서 직접 가져와 ①~⑤ 진행.
- **앱 경로(보조)**: 앱 `/letter-materials`(insights에서 진입) → 텍스트 복사 + 사진 다운로드 → Claude에 첨부. (무료, RLS)

**Claude에 줄 재료 형식 (예)**
```
발행: 2026년 6월 · MFH #2606
이달 핵심: (사역 요약)
사진: (대표 1장 + 섹션별)
```
→ Claude가 ②분석부터 시작.

---

## 6. 출력·활용

- ⑤ 출력: 편지를 브라우저로 열고 `Cmd+P → PDF로 저장` (또는 자동 PDF). 카드 이미지는 우클릭 저장.
- 앱 포트폴리오 *선교편지 관리* 에 업로드(PDF·표지·요약).
- SNS·카톡 공유.
