# MFH-WRITING-GUIDE — 글쓰기 기조 (SoT)

> 2026-11-16 우진 지시로 제정. 일지 교정 · SNS 게시글(weekly_fb · 릴스) · 선교편지 · 기도제목 · 인사이트 등 **MFH 의 모든 글쓰기**에 적용한다.
> 다른 문서(스킬·작업지시서·`MFH-LETTER-AGENTS.md`)의 세부 규칙과 겹치면 이 문서를 우선한다.

## 1. 기본 방향
- 하루의 일을 **담백하게 기록**하되, **순수한 신앙고백으로 모아지도록** 다듬는다.
- **없는 사건이나 장면은 지어내지 않는다.** 일지·캡션에 있는 사실만 쓴다.
- **작위적인 묘사는 넣지 않는다**(꾸민 감탄·장면 연출·과장된 감정 표현 금지).

## 2. 응답 형식 (우진이 글을 주고 다듬어 달라고 할 때)
**교정본 → 교정 내용 → 신앙적 표현 검토 → 확인해 주실 부분 → 스페인어 번역** 순서로 답한다.

## 3. 신앙적 표현 기준
- **주체는 하나님이시다.** "우리가 해냈다"가 아니라 "하나님께서 하셨다"로 쓴다.
- **기도의 응답은 하나님의 주권으로 표현한다.** (기도했더니 이루어졌다 ✕ → 하나님께서 응답하셨다 ○)
- **죽음을 깨달음의 도구로 쓰지 않는다.**
- **한국의 위상이나 선교사·교회를 특별히 선택된 것처럼 쓰지 않는다.** (한국에 대한 호의를 "하나님이 우리에게 열어 주신 특별한 문"으로 해석하지 않는다.)
- **기도는 모든 아이를 품는다.** 모인 아이·잘한 아이만이 아니라 오지 못한 아이까지 함께 기도한다.
- **성경 구절은 개역개정으로 확인한다.** 장절과 본문을 대조해 그대로 인용한다.

## 4. 개인정보
- 공개용 글로 옮길 때는 **실명과 가족의 사적인 사정을 빼도록 권한다.**
- **아이 사진은 보호자 동의를 확인한다.** 공개 게시물에 아이 사진을 추천할 때는 "확인해 주실 부분"에 동의 확인을 적는다.

## 5. SNS 게시글 형식
```
한국어 본문
―
스페인어 본문
#한국어해시태그 #HashtagEspañol …   (한국어·스페인어 짝으로)
```
- 해시태그는 **한국어·스페인어를 짝으로** 나란히 둔다. 예: `#온두라스선교 #MisiónHonduras` · `#주일학교 #EscuelaDominical`
- 릴스 화면 자막은 한국어 구어체 그대로 두고(작업지시서 [릴스 자막 규칙]), **릴스 게시 문구**는 위 형식을 따른다.

## 6. 선교편지와 기도제목
- **날짜와 수치는 뺀다.** ("11월 9~12일", "9명", "40분" 같은 숫자를 쓰지 않는다.)
- **온두라스 지명은 한국어로 풀어 쓴다.** (예: Zapotal → 사포탈, Las Brisas → 라스 브리사스, San Pedro Sula → 산페드로술라)
  - 동향 브리핑(`news-update`)의 지명·인명 원문 철자 규칙은 별개로 유지한다.

## 7. 스페인어
- **온두라스 현지 표현**을 쓴다. 예: `se fue la luz`(정전), `merienda`(간식), `manta`(현수막·천).
- **성경 구절은 Reina-Valera 1960** 본문을 따른다(`docs/MANNA-TO-MFH-RVR1960.md` 참고).
