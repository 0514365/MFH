## 요약 (코드를 안 읽어도 되게)
- **콜라주 배치**(`app/(app)/journal/PhotoCollage.tsx`): 사진 비율(가로/세로)의 합이 줄 목표치에 가깝도록 줄을 나누고(DP), 줄 안에서는 비율대로 폭을 나눠 높이를 맞춘다. 좁은 화면 = 첫 줄 2.4 / 이후 3.4 / 줄당 최대 4장, 넓은 화면(`wide` + `@xl`) = 4.0 / 5.5 / 최대 7장. 비율은 저장된 `w/h` → 없으면 썸네일 로드 때 측정 → 그 전에는 정사각 가정.
- **사진 크기**: 2026-11 일지 8건 24장은 백필 완료. **10월 이전 사진은 미백필** — 처음 열 때 배치가 한 번 움직인다. 없애려면 `npx tsx scripts/backfill-photo-sizes.ts`(월 지정 `--month YYYY-MM`, 미리보기 `--dry`).
- **목록 원본 지연 서명**: 목록의 `CollagePhoto.url` 은 `''`, `path` 만 전달. 라이트박스가 열릴 때 `createSignedUrl`. 상세 페이지는 종전대로 원본을 미리 서명. 목록이 그리는 장수 `LIST_THUMBS`(journal/page.tsx)와 `PhotoCollage max`(JournalList)는 같아야 한다(둘 다 5).
- **30초 캐시 규칙**: 방금 본 화면으로 30초 안에 돌아오면 서버에 다시 묻지 않는다. **새 쓰기 경로를 만들 때는 반드시 `router.refresh()` 또는 `revalidatePath` 를 부를 것**(안 그러면 옛 값이 30초 남는다). 다른 기기의 변경은 최대 30초 늦게 보인다.

- **로컬 빌드**: 개발 서버(`next dev`)를 끈 직후 `npm run build` 가 멈출 수 있다(`.next` 충돌) → 빌드 프로세스 종료 후 `.next` 삭제하고 재실행. `.next` 를 지우면 Google 글꼴을 다시 받으므로 회선이 나쁘면 재시도가 길어진다.

- `scripts/fetch-letter-materials.mjs`: 인사이트 재생성으로 `created_at` 갱신 시 해당 월 인사이트 0건(수정 여부 우진 판단 대기). 수집 스크립트 재실행은 수기 보완한 `materials.md` 를 덮어씀.
