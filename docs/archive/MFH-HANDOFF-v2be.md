## 이번 세션 작업

### ① Figma 연동 검토 → 결론: 코드 우위 (재논의 방지)
- Figma MCP로 표지 1장 변환 테스트 — 뷰어 좌석이나 **드래프트 생성·변환 품질 OK**.
- **결론**: 월간 제작엔 **코드(HTML)+Chrome 캡처가 Figma보다 우수**(자동 조판·일관·무료). Figma는 ① 우진 직접 픽셀 편집 ② 외부 디자이너 협업 때만 꺼낸다. 평소 불필요.

### ② 디자인 전면 재구성 (파스텔 V3 → 에디토리얼 V4)
웹 우수 사례 큐레이션 → **"에디토리얼 × 차콜·레드"**.
- **표지**: 사진 hero 풀(~70%) + 제목 오버레이.
- **사역 사진 내지**: 풀블리드 온전 + 제목은 사진 **밖**(가리지 않음 — 사역 사진은 '증거'. ★우진 핵심 피드백).
- **사진 없는 내지**: 참고사진(02·03) or 본문 중심(07) — 주제별 결정.
- **사진 여러 장**: 분리 / 콜라주(모자이크) / 대표 1장.
- **색**: 차콜 `#17171C` + 레드 `#C5283D` (골드·파스텔 폐기), 슬림 미드그레이 헤더 `#45454F`(70px), 명조 제목 유지.
