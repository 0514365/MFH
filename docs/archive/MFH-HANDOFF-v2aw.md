**할 일·인사이트·사진(캡션)·편지 연동까지 UX 개선 한 묶음 배포 완료.** 일일 3회 자동 루틴이 이제 인사이트 + 비서 + 사진 캡션을 함께 갱신. 코드 작업트리 clean, 전부 푸시됨.

## 이번 세션 배포 묶음 (v2aq → v2av, 모두 푸시 완료)

| 호 | 내용 | SQL |
|---|---|---|
| v2aq | 할일 키워드 검색 · 복제 · 반복등록 / 인사이트 보관 오표시 수정 · 개수→업데이트시각 · 2열·데스크탑 폭 | — |
| v2ar | 목록 다중선택 복제(제목 자동번호) · 반복 종료일 `(필수)` 명확화 | — |
| v2as | **반복 시리즈**(`recurrence_id`) — 뱃지 + 편집/삭제 "이 항목만/이후 모두" 모달 / 할일 폼 데스크탑 2열 전체폭 + 편집폼 복제 | **patch85 실행됨** |
| v2at | Photos 헤더 바로가기 / 사진 캡션 **수동 입력**(수동 우선, AI 재스캔 보호) | — (jsonb) |
| v2au | 수동/AI 캡션을 **선교편지 자료(materials.md)에 반영**(수동 우선) | — |
| v2av | **할 일 편집 페이지 이전/다음**(필터·검색 인지, `DetailNav` suffix) | — |

> 상세는 각 호 핸드오프 참조. 스키마는 **patch85**(tasks recurrence)만 추가됐고 우진 실행 완료.

## 루틴 변경 (repo 밖 — 로컬 예약작업, 이 문서로만 기록)

**일일 3회 자동 루틴에 비서 + 사진 캡션 보충 추가.**

- 대상: `~/.claude/scheduled-tasks/insight-update-{0600,1400,2100}/SKILL.md` (06:10·14:10·21:10).
- 변경 전: 각 회차 `/insight-update` 만(회고 7도메인). 비서(project_assist·task_assist)·캡션은 **수동 전용**이었음.
- 변경 후: `/insight-update` → **`/assistant-update`**(비서 다음행동 제안) → **`/caption-update`**(증분 — 캡션 없는 사진만, 0장이면 즉시 종료, 수동/기존 AI 캡션 보호).
- 비용: 분석 주체 Claude Code(구독·**API 종량 $0**) → 자동화해도 비용 안 늘어 비용민감 방침과 무충돌.
- ⚠️ **repo 파일 아님** — 커밋·배포 대상 아니고, 변경은 `mcp__scheduled-tasks__update_scheduled_task` 로 적용됨. 현황 확인은 `list_scheduled_tasks`.
