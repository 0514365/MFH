## 다음 과제 — 선택 과제 4건(추천 순서, 각 단계 끝에 빌드 → 「커밋 푸시」)

### ④ 항목 관리(수정·숨김) — 1순위, 소
- 위치: 기록 탭 `+ 항목 추가` 옆 / 승인대기 상단에 **"항목 관리"** 버튼 → 모달.
- 기능: 구분(수입/지출) 탭 → 대분류별 목록(사역비/생활비·후원/헌금/기타수입) · 이름·대분류 수정(인라인) · 순서(▲▼ 또는 드래그, `sort_order`) · 숨김/보이기(`is_active`, 거래 유지) · 숨긴 항목 섹션.
- 코드: `ItemManageButton.tsx`(신규) · `actions.ts` `updateItem`/`setItemActive`/`reorderItems` · `accounting-db.ts`. 스키마 변경 없음. 이름 수정은 id 기준이라 과거 거래 표시 자동 반영. 유일성 (구분,대분류,이름) 충돌 시 안내.

### ② 신용카드 자동 승인 — 2순위, 소~중
- `merchant_rules` 에 `auto_approve boolean default false` 추가(patch110). 수집기(`ficohsa-collect.ts`)가 규칙 적중 + `auto_approve` + 금액 ≤ 최근 승인 평균×3 이면 승인대기 대신 장부 저장(`source='sms'`, `card_tx_inbox.status='approved'`, `auto=true` 표시 컬럼).
- 인박스에 "자동 승인 N건(최근 7일)" 접힌 목록 → 되돌리기(장부 삭제 + 대기 복귀). 상점 사전 화면(또는 승인 시 체크박스 "다음부터 자동 승인")으로 토글. 기본은 꺼짐, `hit_count ≥ 5` 인 상점에 켜기 추천 표시.

### ① 영수증 업로드 — 3순위, 중
- Storage 비공개 버킷 `receipts`(patch111: 버킷 + 멤버 RLS), 경로 `YYYY/MM/<inout_id>.<ext>`. 업로드 API(`/api/accounting/receipt`, 이미지 리사이즈 ≤1600px) → `acct_inout.receipt_path`.
- 기록 폼(모바일 카메라 버튼) · 내역 행 📎 아이콘 → 서명 URL 미리보기 · 삭제. 선택: Claude 비전으로 금액·상점·날짜 추출해 폼 선채움.

### ③ iOS 단축어 실시간 수집 — 4순위, 소 + iPhone 설정
- `/api/accounting/sms-ingest`(Bearer 토큰 `SMS_INGEST_TOKEN`): 본문 받아 기존 정규식 파싱(파서를 `lib/ficohsa-sms.ts` 로 공용화) → `card_tx_inbox` upsert(sms_key 동일 규칙) → 푸시. Mac 수집은 백업 유지.
- iPhone 단축어 자동화: 메시지 수신(발신 FICOHSA) → URL 콘텐츠 가져오기(POST JSON `{text, received_at}`), "실행 전 확인" 끄기. 설정 절차를 `docs/MFH-SMS-SHORTCUT.md` 로.
