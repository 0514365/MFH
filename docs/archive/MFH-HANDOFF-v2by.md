## 핵심 메커니즘 (다음 세션 = 프로젝트 디자인 필수 이해)

**일지 모듈에서 확립한 패턴 — 프로젝트/할일에 그대로 이식**:

1. **`.app-theme` 통합** = `import '../p/portfolio-theme.css'`(경로 깊이 주의: 목록 `../p`, 상세 `[id]` 는 `../../p`) + `<main className="app-theme ...">`. 토큰 자동 전환(primary→잉크, accent→마룬레드, 캔버스→순백).
2. **카드 구분** = 흰 배경(`bg-surface`) + `shadow-[0_4px_18px_-6px_rgba(34,34,34,0.16)]` + `border-line`. 미색 배경 금지(우진 어색). [[mfh-list-card-shadow-pattern]].
3. **메타칩** = 회색 pill(`border-line bg-paper text-muted`) + **아이콘만 색**(③ 스타일). 색: 프로젝트 `#B05744` · 할일 `#B08A4A` · 장소 `#9A9A98` · 작성자 김우진(=PORTFOLIO_OWNER_ID) `#5E82A6`(청)·서진아 `#C56A7E`(로즈). 동적 클래스 금지 → hex 직접(`JournalList.tsx` 의 `META_ICON_COLOR` 참고).
4. **사역분류/카테고리 칩** = 회색(`bg-surface-subtle text-primary`), 색 입히지 않음.
5. **상단 여백** = `PageHeader py-2`(이미 전역) + `main` 상단 패딩 0(PageHeader 페이지) 또는 `pt-2`(자체 헤더). py-8 쓰지 말 것.
6. **상세 상단바** = 좌 `‹`(BackButton `label=""`) / 중앙 날짜(16px) / 우 DetailNav. 메타칩은 제목 아래.
7. **입력 폼** = textarea `[field-sizing:content]`+`min-h-[Npx]` 로 모바일 auto-grow, 라벨 행 `h-7` 정렬, 저장 버튼 `bg-accent hover:opacity-90`.

**색 체계**(v2bx 정착 유지): 캔버스 순백 #fff · 본문 잉크 #222 · 강조 마룬레드 #B61821(`text-accent`) · 연틴트 #FAE3E4(`bg-accent-soft`) · 보조면 #f7f7f7.
