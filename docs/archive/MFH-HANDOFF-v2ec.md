## 미확정: 표준새번역 폰트
우진이 "폰트가 달라 보인다"고 함(MFH·Manna). 확인 결과 버전별 폰트 지정 없음, 글자 코드도 새한글과 같은 완성형, 스크린샷 확대 비교에서 같은 글자는 같은 모양. **코드는 바꾸지 않았다.**
체감 원인 추정: 곧은 따옴표(`"` `'`, 새한글은 둥근 따옴표) · 쉼표 2배(약 5만 vs 2.4만) · 숫자 표기("사십 년" vs "40년"). 추정이며 우진 확인 전이다.
둥근 따옴표로 바꾸려면 두 DB 재시딩 필요. 따옴표가 절을 넘어 열리고 닫혀(큰따옴표 홀수 행 4,004개) 변환 규칙 검증이 먼저다.
