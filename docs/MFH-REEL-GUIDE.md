# MFH-REEL-GUIDE — 릴스 제작 지침 (SoT)

> 2026-11-16 확립. 2026 한국문화축제 영상(`media/out/festival-2026-11-unah.mp4`)을 만들며 우진과 확정한 기준이다.
> 주간 릴스(`/fb-update`) · 행사 기록 영상 · 편지 하이라이트 릴스에 모두 적용한다. 글의 기조는 `docs/MFH-WRITING-GUIDE.md` 를 따른다.

## 1. 가장 중요한 원칙 — 스토리가 먼저다

릴스를 만드는 이유는 **하나의 이야기를 전하기 위해서**다. 장면마다 문장을 하나씩 붙이는 것이 아니다.

1. **재료를 먼저 본다** — 그 주제의 일지를 다시 읽고, 사진 캡션과 영상 클립(프레임을 뽑아 내용 확인)을 살핀다.
2. **스토리를 글로 먼저 쓴다** — 일지 기록과 영상 재료로 처음부터 끝까지 이어지는 한 편의 글을 쓴다(준비 → 일어난 일 → 그 안에서 본 것 → 고백·기도). 대본 JSON 의 `reel.story` 에 그대로 남긴다.
3. **스토리를 장면으로 나눈다** — 한 문장이 **2~4개 장면에 걸쳐 이어지게** 끊는다. 문장 중간 장면은 `~하여 / ~하며 / ~했고 / ~으로 / 쉼표` 로 다음 장면에 넘기고, 문장 끝 장면만 `~습니다` 로 맺는다.
4. **장면에 재료를 붙인다** — 나눈 자막마다 어울리는 사진·클립을 고른다. 재료가 없는 문장은 스토리에서 빼거나 고친다(없는 장면을 지어내지 않는다).

**예**
```
① 아침 8시부터 준비를 시작하여
② 봉사 학생들, 교수님들과 함께 천막을 치고 짐을 날랐습니다
③ 행사는 열 시부터였지만
④ 아홉 시 반부터 벌써 많은 학생들이 모였습니다
```
**나쁜 예** — 장면마다 따로 끝나는 문장: `아침 8시, 천막부터 쳤습니다` / `봉사 학생들과 함께했습니다` / `학생들이 모였습니다`

**검증**: 자막만 처음부터 끝까지 이어 읽었을 때 `reel.story` 와 같은 한 편의 글이 되어야 한다.

## 2. 자막 문체
- **합니다체**(`~습니다 / ~니다`). 해요체(`~에요 / ~요 / ~죠`)와 감탄(`…!`)은 쓰지 않는다.
- 화면 설명이 아니라 일지의 이야기를 전하는 내레이션이다. 일지·캡션에 없는 사실, 작위적인 묘사는 넣지 않는다.
- 주체는 하나님. 한국의 위상이나 선교사를 선택된 것처럼 쓰지 않는다. 기도는 오지 못한 아이까지 품는다.
- 장면당 한두 줄(30자 이내). 두 줄 자막 장면은 5초, 한 줄은 4초 안팎.

## 3. 구성
- **한 주제 집중** — 주간 릴스는 한 사역·한 날만. 행사 기록 영상은 한 행사만.
- **여러 날 행사는 날짜순이 아니라 프로그램별로** 묶는다(같은 프로그램이 날마다 반복되면 모아서 한 단락으로). 참석하지 못한 날을 따로 언급하지 않는다.
- `label` 은 단락 제목(프로그램 이름)으로 쓰고, 한 단락의 장면들은 같은 `label` 을 유지한다.
- 길이: 주간 릴스 약 45초(장면 6~8개) · 행사 기록 영상 약 2분(장면 25~30개). 장면 `dur` 합계 = (목표 길이 − 8) + 0.6 × (장면 수 + 1).
- 그 주제의 영상 클립이 있으면 반드시 쓴다(클립 5~7초 · 사진 4~5초).

## 4. 화면
- **가로 사진·영상은 자르지 않는다** — 장면에 `"fit": "letterbox"`. 원본 비율로 가운데 두고, 위 레터박스에 단락 제목(`label`), 아래 레터박스에 자막이 들어간다.
- 세로 사진·영상은 화면을 꽉 채운다. 클립은 `motion`·`zoom`·`focus` 로 얼굴이 한 번은 크게 보이게 한다.
- 음악은 넣지 않는다(게시할 때 앱에서 고른다). 현장음이 크면 `reel.volume`(예 `0.5`)으로 줄인다 — 행사 기록 영상 기본 0.5.

## 5. 게시 문구
- 형식: 한국어 → `―` → 스페인어 → 한국어·스페인어 짝 해시태그.
- **같은 주제의 게시안이 있으면 그 문구를 릴스 게시 문구로 그대로 쓴다.** 같은 행사를 게시안 여러 건으로 나누지 않는다(한 행사 = 한 게시안).
- 아이 얼굴이 나오면 보호자 동의를 확인한다.

## 6. 제작 절차
1. 재료 확인(일지 · 사진 캡션 · 클립 프레임) → 2. `story` 작성 → 3. 장면 분할·재료 배정 → 4. 대본 JSON(`insights-archive/_fb/*.json`) 저장
→ 5. `npx tsx scripts/make-reel.ts <json>` → 6. 프레임을 뽑아 자막·화면 검수 → 7. 우진에게 장면표(시간 · 제목 · 자막 · 파일)와 함께 보고.

대본 JSON 예: `insights-archive/_fb/festival-2026-11.json`(gitignore — 로컬에만 있음).
