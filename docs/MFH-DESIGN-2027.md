## 1. 한 줄 정의
**흰 화면 위에 색 면으로 영역을 나누고, 글자는 남색 하나로 읽히게 한다.** 강조는 터키석 하나(＋), 정보는 파스텔 블록·알약·옆줄로, 비교는 도넛·막대로.

## 2. 원칙 7

## 5. 모양·간격
- 반경: 알약 `rounded-full` · 면/카드 `rounded-2xl`(16) · 작은 면 `rounded-xl`(12) · 키 `rounded-[12px]` · 블록 **직각**(묶음 바깥만 둥글게, 틈 3px 흰색).
- 간격: 섹션 사이 `space-y-5`(20) · 면 안 패딩 12~16 · 행 세로 10~12.
- 그림자: ＋ 버튼과 돌출 홈 원만. 나머지 0.
- 누름: `active:scale-[0.97]` 또는 `active:opacity-70~80`.

## 7. 화면 패턴
- **상단 고정 + 목록 스크롤**: 제목 줄·상태 알약·달력을 헤더(52px) 아래 `sticky`, 목록만 스크롤(달력 홈).
- **아래로 당겨서 기록**: 창 맨 위에서 80px 당기면 기록 화면. 고정 묶음 아래 틈이 벌어지고 임계점에서만 메시지.
- **필터 묶음 = 연회색 면**, 목록은 흰 바탕. 월 머리줄은 그달 순액 부호 색(수입 초과 연한 파랑 · 지출 초과 연한 빨강).
- **행 2줄**: 제목(항목 · 내용) / 보조(MM/DD · 구매처 · 계좌 · 대분류=종류색). 행별 삭제 버튼 없음 → 체크 선택 → 액션 바.
- **접힘 기억**: 접힘/펼침은 기기별 `localStorage`, 조건부 자동 펼침(카드대금 상환 3일 전).

## 7-1. 메인 홈 (2026-10-21 실기 피드백 C안)
- **미니멀 유지**: 카드(주제·QT·통독·동향)는 연회색 면 하나. 틴트 면·타이틀 알약을 카드마다 쓰면 "미니멀에서 멀어짐"(A안 기각). 구분은 라벨 앞 8px 색 사각형만.
- **블록 글자**: 기존 파스텔 + 흰 글자 + 지금 할로(원칙 6) 유지. 진한 톤 글자(A안)·1px 외곽선·진한 할로는 시안에서 기각.
- **배치**: 승인대기 알약 → 주제 → **모듈 블록 격자(전폭 3열)** → QT·통독·동향. 목표 목록은 옆줄 없이 줄글.
- 격자 컨테이너에 `self-start` 를 주면 flex 열에서 폭이 내용만큼 줄어든다(모바일 70% 폭 버그) → 넓은 화면(@4xl)에서만.

## 9. 전체 앱 개정 순서(다음 세션 제안)
1. **토큰 승격**: 틴트·소프트 토큰 추가 → 회계 리터럴 치환 → `.theme-2027` 를 `:root` 로 승격(`app/layout.tsx`·`globals.css`), `app-theme`/`portfolio-theme.css` 브릿지 제거 범위 결정(`/p` 공개 포트폴리오는 별도 유지).
2. **공용 셸**: 상단 헤더(흰 바탕·Manrope 제목·🔍)·하단 탭바(아이콘+라벨·돌출 홈)·사이드바(md)를 2027 부품으로.
3. **메인 홈**: 연 주제 면 · 모듈 타일 = 숫자 블록(참고 시안의 문자 타일) · QT/뉴스 카드 = 요약 면.
4. **모듈별**: 일지·프로젝트·할 일·인사이트·말씀·후원자 순. 목록 = 2줄 행 + 색 사각형, 상세 = 요약 면 + 옆줄 섹션, 폼 = 알약 세그먼트 + 블록 선택.
5. **로고 재채색**(남색·터키석) · 스플래시 · PWA 아이콘 · 편지 템플릿(2027호부터).
6. 다크 모드는 토큰 한 벌 추가로(이번 범위 밖).
