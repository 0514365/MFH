### 회계 환율 기준(2026-10-16 결정 — 핵심)
| 구분 | 기록 | USD 환산 |
|---|---|---|
| 수입·지출·조정 | **원통화 금액만**(폼·승인대기·반복 기록에 환율 입력 없음) | 그달 **마감 환율**(fx_closings), 없으면 최신 공시(fx_rates, 잠정) |
| 통화가 다른 이체(환전·카드 상환) | **양쪽 실제 금액**: `principal`(출금 계좌 통화) + `to_principal`(입금 계좌 통화) | 실제 교환 비율(USD 쪽 금액 = 금액USD) |
| 같은 통화 이체(비 USD) | 원통화 | 마감·공시 환율 |
| 현재 자산 | 계좌별 원통화 실보유 | 최신 공시 환율 평가(미실현 평가손익 표시) |
- **DB 트리거 `acct_inout_apply_fx`**(patch116, BEFORE INSERT/UPDATE)가 모든 입력 경로(앱 폼·카드 문자 승인·자동 승인·반복·CSV·스크립트)의 rate·amount_usd 를 최종 결정. **2026-09-01 이전 거래는 손대지 않음**(저장 금액USD 확정). 예전 방식 통화 간 이체(입금 금액 없음)도 입력값 유지.
- `acct_fx_rate(cur, date)` = 그달 마감 → 최신 공시. `acct_restate_month('YYYY-MM')` = 그달 재계산(트리거 재실행).
