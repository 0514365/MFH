## 프로세스 배움 (다음 호 필수)

1. **우진 교정 패턴**: 도입은 "인사→이번 호 소식→감사" 평이한 흐름(장면형·역설형 도입 기각). 제목에 정보(교회명·날짜) 우선. 캡션은 사역분야만("어린이 VBS"). 세로 사진은 세로 비율로. 동일컷 2장 금지. 렘피라 등 현지 단위는 달러+원화로.
2. **공유**: 로컬 `python3 -m http.server 8899`(issues/2026-06에서) + **cloudflared quick tunnel**(brew 설치됨, `cloudflared tunnel --url http://localhost:8899`) — localhost.run(ssh)은 불안정해 폐기. 터널 URL은 세션마다 바뀜. 세션 재시작 시 서버·터널 둘 다 죽음 → 재가동 필요. 외부 노출은 **우진 명시 승인** 필요(개인사진·계좌).
3. **PDF**: 원본 사진 그대로면 156MB → `photos-web/` 리사이즈(sips 1600px·q72) 치환 사본(`_print.html`)으로 24.9MB. Chrome headless `--print-to-pdf`, 810×1013pt=1080×1350 확인.
4. **로고 깨짐**: 파일 단독 열람 시 `../../assets/` 끊김 → 모바일은 base64 임베드로 해결(카드뉴스는 파일 참조 유지 — 로컬 PDF 출력용).
5. **designer**: 큰 HTML은 베이스 cp 후 **Edit 부분 수정**(전체 Write 금지 — 리허설·이번 모두 검증). 카드 넘침은 solo 렌더(다른 stage display:none)로 검수.
6. **zsh 함정**: `for f in $VAR` word-split 안 됨 → `| while read f` 사용. sips crop(--cropOffset) 미동작 → 임시 HTML로 부분 렌더.
