- `app/journal/PhotoCollage.tsx` (마커 V1→V2): 상세 전용 **`wide` prop** 추가 — 전체폭에서 세로로 길어지지 않게 데스크탑 가로 밴드형 재배치.
  - 1장: 4:3 → 데스크탑 16:9 / 2장: 정사각 → 데스크탑 4:3 / 4장: 2×2 → 한 줄 4칸 / 5장+: 2+3 두 줄 → 한 줄 5칸(모바일은 6칸 그리드 + col-span 으로 기존 2+3 재현).
  - **`wide` 미지정(목록 JournalList)·모바일은 기존 그대로.**

### 함정 (레이아웃 후속 작업 시)
- PhotoCollage 는 목록·상세 공용 — 상세 전용 변경은 반드시 `wide` 분기로. 목록 쪽 배치를 건드리면 홈/일지 목록 카드가 같이 변함.
- iPad 세로 태블릿 기준은 `sm:` 사용(v2cr 참조, iPad mini 744px). 일지 상세 데스크탑 분기는 `min-[740px]`.
