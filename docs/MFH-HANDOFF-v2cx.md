## 이번 세션 작업

### 온두라스 동향 기상 용어 규칙 (커밋 `733415c`, push 완료)
계기: 우진 지적 — "건조회랑·열대파동은 익숙하지 않은 용어".

`.claude/commands/news-update.md` 3단계(정리·작성) 규칙에 **2개 항목 추가**(+11줄):

1. **기상 용어 쉬운말 표** — 원어·현지 용어는 **첫 등장 괄호 1회까지만** 병기, 이후엔 쉬운 말만.
   | 원어 | 표기 |
   |---|---|
   | onda tropical / 열대파동 | 비구름대 (정확도 필요 시 열대 기압골) |
   | Corredor Seco / 건조회랑 | 중미 건조지대 |
   | canícula / 카니쿨라 | 우기 중 마른 더위 |
   | vaguada / 지표 골 | 기압골 |
   | polvo del Sahara | 사하라 사막 먼지 |
   | alerta verde·amarilla·roja | 주의(녹색)·경계(황색)·심각(적색) 경보 |
   | 뇌우 | 천둥·번개를 동반한 비 |

2. **열대 기상 세기 사다리** — 급을 올리거나 낮춰 부르지 않는다.
   `onda tropical` = 비구름대 → `depresión tropical` = 열대저압부 → `tormenta tropical` = 열대성 폭풍 '○○' → `huracán` = 허리케인 '○○'(○등급)
   - 이름 붙은 폭풍·허리케인은 **반드시 이름 표기**(독자에게 심각도 신호).
   - 등급은 숫자로만, "초강력" 등 자체 수식 금지.
   - **"태풍" 금지**(북서태평양 명칭) — 꼭 필요하면 `허리케인(태평양의 태풍에 해당)`으로 첫 언급 1회만 풀이.

적용 범위 = **동향 스킬만**(선택지 A). 편지 지침(`docs/MFH-LETTER-AGENTS.md`)에는 미반영 — 필요 시 다음 세션에서 B 적용.
